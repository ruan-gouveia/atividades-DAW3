# Atividades - DAW III

Repositório com as atividades desenvolvidas na disciplina de **Desenvolvimento de Aplicações Web III** do IFPB, utilizando **React + Vite**.

🔗 **[Acesse as atividades online](https://atividades-daw-3.vercel.app)**

---

## 📁 Atividades

### Atividade 1 — Cadastro de Disciplinas
Formulário de cadastro de disciplina com os campos: Nome, Descrição, Curso, Período, Professor e Quantidade de Alunos. Ao submeter, exibe um modal com as informações preenchidas.

### Atividade 2 — Páginas de Professores
Sistema Single Page com menu de navegação entre páginas de professores. Cada página exibe as disciplinas do professor e um formulário de contato.

---

## ▶️ Como executar localmente

Certifique-se de ter o [Node.js](https://nodejs.org) instalado.

### Atividade 1
```bash
cd cadastro-disciplinas
npm install
npm run dev
```

### Atividade 2
```bash
cd paginas-professores
npm install
npm run dev
```

Acesse `http://localhost:5173` no navegador.
